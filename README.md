# A股回测与选股系统

一套本地运行的 A 股量化工具，把「股票回测」和「智能选股」整合在一个程序里。既能用经典策略回测历史行情，验证交易想法是否靠谱；也能扫描全市场，找出符合特定条件的股票。提供 Web 网页和命令行两种使用方式。

## 功能总览

| 能力 | 说明 |
|------|------|
| 股票回测 | 内置 9 种交易策略，模拟 A 股真实交易规则 |
| 智能选股 | 3 种选股模式，扫描全市场并给出推荐与止盈止损位 |
| 绩效评估 | 自动计算年化收益率、最大回撤、夏普比率等核心指标 |
| 可视化报告 | 生成 HTML 报告，含资金曲线、回撤曲线、交易明细 |
| 双端入口 | 网页界面 + 命令行，按需选择 |

## 安装

依赖 Python 3.10+，首次使用先安装依赖：

```bash
pip install -r requirements.txt
```

依赖包含：`akshare`（行情数据源）、`pandas`、`numpy`、`flask`。

## 快速开始

### 网页界面

最省事的方式是双击项目目录下的 `start.bat`，脚本会自动启动服务并在几秒后打开浏览器；关闭那个黑色窗口即可停止服务。

> `start.bat` 内部写死了 Python 3.11 的完整路径，这样即使电脑里装了多个 Python，也能确保用的是装了依赖的那个环境。如果你重装或升级了 Python，需要同步修改脚本里的路径。

也可以手动启动：

```bash
python webapp.py
```

浏览器打开 http://127.0.0.1:8000，在网页上完成选股和回测。

### 命令行

```bash
python main.py              # 进入交互式菜单
python main.py --list       # 查看内置策略
```

## 一、股票回测

回测的核心是回答一个问题：**某个交易策略，在过去真实的行情里，到底赚不赚钱。**

系统会拉取指定股票的历史日线数据，按策略生成买卖信号，再模拟真实交易，最后统计收益和风险。

### 内置策略

| 策略名 | 逻辑 | 默认参数 |
|--------|------|---------|
| `ma_cross` 双均线 | 短均线上穿长均线买入，下穿卖出 | 5日/20日 |
| `macd` | DIF 上穿 DEA 金叉买入，死叉卖出 | 12/26/9 |
| `rsi` | 超卖区（<30）回升买入，超买区（>70）回落卖出 | 14日 |
| `bollinger` 布林带 | 触及下轨回升买入，触及上轨回落卖出 | 20日/2倍标准差 |
| `kdj` | 低位金叉买入，死叉卖出 | 9/3/3 |
| `volume_price` 量价配合 | 放量突破 20 日高点买入，跌破 20 日低点卖出 | 1.5倍量 |
| `grid` 网格交易 | 以均线为中枢，跌一格买入、涨一格卖出，赚震荡差价 | 20日均线/5% |
| `dca` 定投 | 每隔固定交易日买入固定金额，长期持有 | 22日/1万元 |
| `turtle` 海龟法则 | 突破 20 日高点买入，跌破 10 日低点卖出 | 20日/10日 |

### A股交易规则模拟

回测并非简单按收盘价成交，而是尽量贴近 A 股真实约束：

- **T+1 制度**：当日买入的股票，次日才能卖出
- **涨跌停限制**：涨停价无法买入，跌停价无法卖出（主板 10%，创业板/科创板 20%）
- **最小交易单位**：按一手 100 股取整
- **交易成本**：佣金万 2.5（最低 5 元）、印花税卖出千 0.5、过户费万 0.1
- **次日开盘成交**：当日收盘发出的信号，在次日开盘价成交，避免"用未来数据作弊"

### 绩效指标

每次回测自动计算以下指标：

- **总收益率**、**年化收益率**：整体和按年折算的收益
- **最大回撤**：历史最大亏损幅度
- **夏普比率**：每承担一份风险能换来多少超额收益
- **胜率**、**盈亏比**：盈利交易占比、平均盈利与平均亏损之比
- **交易次数**：回测期间完成的买卖次数

### 回测用法

命令行一行回测：

```bash
python main.py --strategy ma_cross --stock 600519 --start 2020-01-01 --end 2024-12-31
```

网页端则在「策略回测」页选策略、填股票代码和日期区间，点运行即可。回测完成后会生成 HTML 报告，包含资金曲线（对比买入持有）、回撤曲线和逐笔交易明细。

## 二、智能选股

选股回答的是另一个问题：**现在全市场里，哪些股票值得关注。**

系统先判断大盘状态，再扫描全市场几千只股票，按不同模式的条件筛选、打分、排序，最后输出推荐列表。

### 三种选股模式

#### 1. 综合推荐

多维度打分，适合日常找机会。打分由四部分组成：

- **技术面（40%）**：均线多头排列、MACD 金叉、放量突破、KDJ 金叉等信号
- **基本面（30%）**：估值（PE/PB）、盈利能力（ROE）、业绩增长
- **资金面（20%）**：主力净流入、北向增持、换手活跃度
- **风险控制（10%）**：高位预警、换手过高、放量滞涨等减分项

输出每只股票的现价、PE、综合得分和推荐理由。

#### 2. 超跌反弹 · 60日线

专门找「**中长期趋势向上 + 近期短期超跌**」的股票，博反弹。筛选条件：

- 60 日均线向上（趋势向上）
- 近 5 个交易日累计跌幅 ≤ -10%（短期超跌）
- 排除 ST、停牌、涨跌停、流动性不足

每只推荐股票直接给出**建议买入位（当前价）、止盈位（+8%）、止损位（-5%）**。

#### 3. 超跌反弹 · 120日半年线

与上一个模式相同，只是趋势判断改用 **120 日均线（半年线）**。半年线反映更长周期的趋势，选出的股票趋势更稳，但也更滞后。

### 选股用法

网页端在「选股推荐」页切换"推荐模式"，选数量，点"开始扫描"即可，进度会实时显示。

命令行：

```bash
python main.py --recommend                      # 综合推荐
python main.py --recommend --mode dip           # 超跌反弹（60日线）
python main.py --recommend --mode dip120        # 超跌反弹（120日半年线）
```

## 三、数据源

行情数据通过 `akshare` 获取，系统内置**三级自动降级**，某个源失效时自动切换，避免单个数据源故障导致整体不可用：

| 优先级 | 数据源 | 特点 |
|--------|--------|------|
| 1 | 东方财富 | 字段最全，首选 |
| 2 | 腾讯 | 字段较全，含 5/10/20/60 日涨跌幅 |
| 3 | 新浪 | 兜底 |

个股历史数据同样支持自动降级（东方财富 → 新浪）。首次拉取的数据会缓存到本地 `data_cache/`，之后增量更新，重复扫描会明显变快。

> 说明：这些免费行情接口面向浏览器设计，程序频繁抓取可能触发反爬。系统通过多数据源自动切换来规避这一问题，若某天所有源都临时不可用，稍等片刻重试即可。

## 五、配置说明

交易成本和默认参数都在 `config.py` 中，可按需修改：

```python
COMMISSION_RATE = 0.00025    # 佣金万 2.5
MIN_COMMISSION = 5.0         # 最低佣金 5 元
STAMP_TAX_RATE = 0.0005      # 印花税（卖出单边）
TRANSFER_FEE_RATE = 0.00001  # 过户费（双边）

INITIAL_CASH = 100000.0      # 回测初始资金 10 万
TOP_N = 10                   # 默认推荐股票数量
CANDIDATE_LIMIT = 50         # 深度分析候选数量
```

超跌反弹的筛选参数（短期跌幅 -10%、止盈 +8%、止损 -5%）目前为代码内默认值，调整需修改 `screener/dip_scanner.py` 中 `scan_dip` 的入参。
